# UI6：息屏位置、内置照片与渲染优化

版本：`0.5-alive.7-ui.6` / `21`，安装包名仍为 `com.xtg.hyperextremealive`。

## 本次修改

- 照片息屏的横纵向偏移均支持双向调整。旧版纵向最低值为 `-0.02`，向上调整范围过小；现在为 `-0.45..0.45`。
- 息屏预览底栏为动态壁纸增加「位置」。编辑器草稿、界面重建、已应用设置均保存动态位置；调整位置会切换为固定模式，防烧屏位移仍可独立保留。
- 系统时钟优先识别内部内容，排除空白容器、占位 View、空文本和空图片；文字使用实际布局边界，保留系统已有的平移。拒绝过大的宿主边界、过期数据和不匹配的屏幕方向。
- 内置 HyperAlive 原包的示例照片，首次进入即可预览。预览、真实渲染和六款样式缩略图使用同一来源，不再借用立体壁纸图片。显式选中的照片即使丢失，也不会被默认图悄悄替换。首次释放图片在后台线程完成。
- 缓存照片渲染中没有变化的锁屏、桌面和模糊结果；输入、取景、颜色或纹理参数变化时失效。减少缩略图照片解码尺寸，按需创建亮度后处理资源，照片等平面渲染不再申请不必要的多重采样。
- 合并预览 Surface 回调与场景更新的绑定入口，跳过已过期的待绑定任务；不丢弃电源状态事件。

照片、桌面独立选图、纹理和关于页作者资料均保留。本轮不引入小米超级壁纸，不重做系统真实时钟预览。

- 六款照片横竖屏管线、电源事件中断、隐藏停绘、双实例、亮度回调、真实缩略图通过。12 次跨渲染类别切换通过，EGL 资源释放检查通过。

## 性能测量边界

同一 Java 宿主、资源、EGL 配置和 `1200×2670` 分辨率，仅切换 UI5/UI6 的原生库；每种状态预热 20 帧，再测 90 帧，以 `glFinish` 等待 GPU 完成。

| 稳定状态 | UI5 P50 | UI6 P50 | UI5 P95 | UI6 P95 |
| --- | ---: | ---: | ---: | ---: |
| 圆景息屏 | 5.79 ms | 2.61 ms | 6.13 ms | 3.24 ms |
| 锁屏 | 2.40 ms | 2.65 ms | 3.02 ms | 3.25 ms |
| 桌面 | 4.14 ms | 3.16 ms | 5.56 ms | 3.81 ms |

该测试证明的是相同画面下的重复 GPU 工作减少，不等于前台帧率或续航同比提升。后台 ImageReader 窗口的转场帧间隔测量存在调度波动，未得到所有场景一致提升的结论；原始记录一并保留。

## 安装与实机验收

已通过 `adb install -r` 覆盖安装 UI6 并核验 `versionCode=21`，随后打开应用。没有卸载、清空用户数据、自动应用壁纸、模拟电源按键、改动 LSPosed 数据库或重启系统进程。本轮未推送源码，也未创建 GitHub Release。

请在手机上重新选择所需位置并应用。手动定位时自动关闭「跟随系统息屏时钟」，这是避免系统锚点覆盖人工位置的明确行为；希望继续跟随时可重新打开。防烧屏微移默认保留，因此固定位置仍可能有很小的周期偏移。

系统进程中的时钟跟踪代码需要用户重启手机后加载。真实 ROM 时钟布局、实体电源键反复息屏/亮屏及长期使用稳定性仍需用户验收，隔离测试不能代替这些环节。Vivo 已测试跨类别切换，尚未逐个模板验收新位置设置。全屏背景整体移动可能在边缘露出黑色，适合按实际息屏构图调整。
