# 预览内选择动态壁纸：0.5-alive.7-ui.2

日期：2026-11-06。versionCode 17。基于上一份 ui.1 交付修改，未安装候选或改变手机壁纸。

## 使用方式

预览底栏「样式」→「照片壁纸 / 动态壁纸」→选择缩略图。选择后收起面板，在当前
预览界面显示新壁纸；息屏、锁屏、桌面均可使用，保持切换前的预览模式。

- 动态壁纸复用 AliveCatalog、AliveThumbnail 和原壁纸库缓存，不新建一套示意缩略图。
- 分组与壁纸库共用：全部、启航、流光、轻启、视频、立体、Vivo。
- 照片部分保留六种真实息屏造型，共用 ui.1 的缩略图组件及缓存。
- 当前选中项标记的是预览选择，不把它标记为「正在使用」。只有「应用」并确认才发布。
- 从动态切回照片保留原照片和裁切。选择具体照片造型会恢复动态造型模式。
- 液态、光栅、闪卡切换前保存对应家族草稿，进入时加载正确家族；避免上一种素材/效果
  套到下一种引擎。选中标题同步更新，演示停止，新引擎从当前预览模式初始化。
- 选择面板用有界可滚动网格，窄屏/大字体改为两列；保留加载和失败重试状态。
