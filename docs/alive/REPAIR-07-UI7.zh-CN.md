# UI7：应用启动与页面按需加载

版本：`0.5-alive.7-ui.7` / `22`，包名仍为 `com.xtg.hyperextremealive`。

## 修改

- 交付包由 Debug 改为开启 R8、资源收缩的 Release，包含依赖提供的 ART 基线配置。打包脚本只接受匹配版本的 Release，同时归档 R8 映射，便于还原崩溃栈。
- 首页不再预读遮罩候选和视差大图，也不提前组合整个相邻功能页。遮罩与视差页面分别按需加载自己的图片；图片保留原有分辨率上限。
- 功能卡片的系统图标改为后台读取，同一页面的重复包名共用有界缓存。图标按显示尺寸绘制，加载期间保留占位尺寸，避免文字位置跳动。
- 页面图片缓存合并重复的首次加载、恢复前台及偏好通知。导入修订号与文件状态共同决定失效，避免同尺寸、同时间戳的新图片被错误复用。
- 合并同一批偏好变更的界面刷新；页面销毁时注销监听并清理待执行刷新。

保留既有 Miuix 布局、页面切换动画和启动窗口过渡。本轮不修改壁纸渲染、电源状态、时钟定位、已应用设置和关于页。启动事务恢复与候选清理的时序保持不变。

## 验证

- `:app:testDebugUnitTest`：116 项通过，无失败或跳过；新增 9 项按需加载、后台解码、缓存失效、并发合并及监听释放测试。
- `:app:assembleRelease` 构建成功，含 `lintVitalRelease` 检查。未把该检查等同于完整 Lint；完整 Lint 的上轮遗留问题见 UI6 记录。
- 1276 项结构/资源检查通过，另有状态、权限、取景和动画回归。
- 直接加载优化 APK 的隔离真机测试通过 42 个场景：五类动态代表、六款照片、Vivo 三类效果，各检查息屏/锁屏/桌面帧。驱动只编译测试反射代码，没有重新编译生产 Java 来覆盖 R8 结果。
- 486 个非基线配置资源资产与 UI6 APK 逐字节一致。签名与已安装版本相同，APK 的 16KB 对齐检查通过。
- 已通过 `adb install -r` 覆盖安装，设备报告版本 22 且不含 `DEBUGGABLE`；安装后 APK 校验和与本机构建一致。5 个现存 Alive 偏好文件安装前后校验和相同。

安装后启动命令返回成功，但手机停留在锁屏，系统报告 `LaunchState: UNKNOWN`，没有可比较的首帧冷启动数据。命令等待的 50ms **不作为启动耗时**。没有为跑分强制停止真实壁纸进程、模拟电源键、解锁手机或重启系统。

仍需用户解锁后验收：首次进入首页、第一次切到功能页、返回应用，以及首次打开 Alive 预览。离屏测试不覆盖整个 Compose 界面、真实电源切换、视频和长时间运行。
