# Alive 动态壁纸独立资源包

适用于 `0.5-alive.7-ui.21-resources1`（versionCode 36）。

## 使用

1. 安装精简版 APK，打开 **Alive → 动态壁纸**。
2. 点击 **去下载**，选择 **夸克网盘**或 **GitHub**。
   - 夸克：直接复制预设分享文案，只提示“分享内容已复制，请打开夸克网盘”；应用与系统剪贴板预览均不展示链接正文。
   - GitHub：通过系统打开 `https://github.com/XTG-xtg/HyperExtremealive`。
3. 获得 `HyperExtreme-Alive-Dynamic-Wallpapers-v1.zip` 后，点击 **导入动态壁纸**，选择 ZIP，无需解压。
4. 未导入时隐藏分类，屏幕中央上下排列“导入动态壁纸”和“去下载”。导入完成后隐藏这两个按钮，显示分类及壁纸缩略图，可以预览和应用。导入本身不会切换壁纸或修改当前预设。

下载入口已配置；本次只生成本地文件，没有上传资源包到网盘或 GitHub。发布前需要将同一份配套 ZIP 放到上述渠道。

## 拆包范围

外置 **启航、流光、轻启、视频、立体**使用的大型纹理、视频、网格和缩略图，共 48 个文件，原始数据 46,244,991 字节。渲染代码、GLSL 和小型场景参数留在 APK。

Infinity、照片壁纸、液态/光栅等 Vivo 系列继续内置。它们不需要这个资源包。时钟替换与通知光效在 ui22 中已删除。

源文件仍保存在 `app/src/main/assets` 中；构建阶段生成单独的 APK 资源目录，排除外置数据。资源 ZIP 没有降画质或改变素材内容。

升级精简版后，如之前正在使用上述五类动态壁纸，需要先导入资源包以恢复渲染。已有设置和预设元数据保留；缺少资源时，首页提供导入入口，阻止无资源的动态壁纸预览/应用，仍允许使用照片和其他壁纸系列。

导入资源在应用私有目录。后续覆盖安装使用相同资源清单的版本可以继续使用；卸载应用或清除数据后需要重新导入。已导入素材会占用设备存储，因此此次优化减少 APK 下载大小，不等于将所有使用场景的设备总占用减少同样大小。

## 格式与完整性

- 根目录 `manifest.json`，素材位于 `assets/<原路径>`。
- 版本格式 1，资源 ID `alive-dynamic-v1`；清单必须与 APK 内置清单完全一致。
- 每个文件验证大小与 SHA-256，拒绝缺失、重复、未知文件以及越界路径。
- 在临时目录中完成校验和同步落盘后，整体发布；失败或协程取消时清理临时目录，并保留已有完整资源。
- 媒体解码器通过私有文件描述符读取视频；纹理和模型通过统一资源读取器打开。
- 不加载来自 ZIP 的 DEX、动态库或脚本；当前配套 ZIP 只包含数据。

构建脚本：`tools/dynamic_resource_pack.py` 与 `tools/pack_alive_assets.py`。资源输出：`build/dynamic-wallpapers/`。未来素材变更必须同步发布新清单与资源包，并调整发布名称，避免渠道上混用不同版本。

## 验证范围

自动化测试覆盖实际配套 ZIP 的导入、每个外置文件的读取与摘要、视频描述符、异常/中断导入、偏好保留、缺失资源提示、系统文件选择器回调、下载选项及深浅主题。

这些测试使用 Robolectric；并不代表已在小米 15 验证 GPU 渲染、息屏动画或 HyperOS 桌面手势。本次未修改 Rust 桌面 Hook 或之前的音乐问题。
