# ui35：Infinity 稳定星点与 Doze 会话亮度

版本：50 / `0.5-alive.7-ui.35-aod-fixed`。

ui34 重启后日志已确认系统壁纸遮罩为 0。采集到的 AOD 会话中，系统显示亮度从亮屏档切入约 32 nits 后保持同一档，不能据此断言此次闪烁就是自动亮度变化。

检查渲染代码发现两个独立的亮度变化来源：S8/N8 及多边形公共星点叠加了约 1.6 秒的增强脉冲，多边形在进入 AOD 时还会把已经可见的星点分组归零，并在约 3.4 秒后单独降低高光。

- 移除公共星点增强脉冲，保留稳定 AOD 的星点增益、移动、背景淡出和桌面手势。
- 多边形切换继承当前星点分组的显示程度，不再归零；高光与几何参数同时过渡，不再延迟单独变暗。
- 对实际绑定本模块 Home／Lock／Spatial／Raster 服务、启用全屏 AOD 且亮度非零的会话，保持首次有效 Doze 亮度请求，后续环境光不再改变该请求。
- 同一会话移除 `DozeServiceHost.setAodDimmingScrim` 的部分压暗层。完整黑色遮挡仍交还系统；不拦截普通桌面／锁屏亮度接口。
- 唤醒、壁纸解绑、亮度为 0、Doze 结束或显示完全 OFF 时释放会话。数值无效或系统接口不匹配时保留系统路径。温控等后续系统约束照常执行。

回归覆盖 20 款 Infinity 的亮度不超调、槽位接管、快速反向、分组首帧连续性，以及 Doze 会话保持／释放、0 值、黑屏与无效输入。实机视觉效果仍由用户测试确认。
