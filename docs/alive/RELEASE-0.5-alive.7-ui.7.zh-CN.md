# HyperExtreme Alive 首个正式版

`0.5-alive.7-ui.7` · versionCode `22` · ARM64 / Android 13+

基于 HyperExtreme，面向 HyperOS 整合 Alive 壁纸体验。不包含小米原有超级壁纸。

## 主要功能

- 圆景、留光、星月、轻启、山脉、银河六款照片壁纸，内置示例照片。
- 动态壁纸及 Vivo 液态、趣味光栅、闪卡效果，支持息屏、锁屏和桌面预览。
- 锁屏与桌面独立照片、纹理和取景；桌面照片可跟随锁屏。
- 预览内切换壁纸和息屏样式、调整息屏位置与亮度，支持跟随系统息屏时钟及防烧屏位移。
- 保留主线的空间、光栅、视差壁纸及系统个性化功能，完善并排圆形作者头像与主页入口。

## 本版优化

修正息屏位置与设置恢复，减少照片渲染中的重复 GPU 工作；首页不再预读无关大图，功能图标后台按需加载。安装包采用 R8 优化的 Release 构建，保留原有界面过渡动画。

## 安装与兼容性

直接下载 `.apk` 安装即可。同包名 UI5 / UI6 / UI7 测试版可覆盖安装并保留配置；已经安装 UI7 的用户无需重复安装，本次发布的 APK 与已验证的 UI7 包一致。

包名为 `com.xtg.hyperextremealive`，与主线独立。旧包名不会自动迁移配置。需要系统钩子的功能请在 LSPosed 中启用模块、确认推荐作用域后重启手机；不要同时启用主线和本分支中修改相同系统功能的选项。

主要适配澎湃 OS 4，其他 ROM 不保证兼容。OpenAlive 的通知光效、原版时钟编辑器及完整指纹遮罩联动尚未接入，详见[功能清单](INTEGRATION-MATRIX.zh-CN.md)。

116 项单元测试、1276 项结构与资源检查，以及优化 APK 的 42 个代表性真机离屏渲染场景通过。尚无可比较的冷启动耗时数据；真实 ROM、电源切换及长期稳定性仍需实机反馈。详细验证记录见 [UI6](REPAIR-07-UI6.zh-CN.md) / [UI7](REPAIR-07-UI7.zh-CN.md)。

附件包含 APK、完整源码、R8 映射及 SHA-256 校验文件。感谢 HyperExtreme、HyperAlive 与 OpenAlive 的作者；相关署名和许可保留在项目中。
