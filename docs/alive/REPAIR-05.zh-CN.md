# 第五轮：照片性能、息屏位置与编辑流程

候选版本：`0.5-alive.5` / versionCode 10。日期：2026-11-05。

## 性能改动

- **静止照片不重复提交帧**：留光相框、展开后的静态照片在动画结束后停止绘制；状态变化、取景修改、可见性变化或缺失蒙版解码完成时重新唤醒。不能用静止区间 FPS=0 判定渲染故障。
- **圆球区分自转与转场**：稳定 AOD 自转按约 30fps 上限调度；展开/收拢仍每个 vsync 更新。使用真实经过时间计算旋转，不因降频改变旋转速度。屏幕自身低刷新率可能令实际帧率更低。唤醒/编辑事件会取消等待中的低频回调。
- **留光方向预读**：原实现首次遇到每张蒙版才开始解压，常跨一帧等待。现在预读运动方向前方的短窗口，缓存首尾帧；反向事件重新确定优先级。始终等正确蒙版及其整组几何/纹理采样就绪，不把旧蒙版配到新几何。
- **复用蒙版纹理存储**：尺寸不变时使用 `glTexSubImage2D`，不再逐帧重新分配纹理。
- **缓存有界**：720px 蒙版每引擎最多 8 个直接缓冲，约 11.9MiB；两槽最多约 23.8MiB，比原 4 帧缓存占用更多内存。这是用有限内存减少实时解压等待，没有解码整套约 98MB 蒙版常驻。
- **壁纸库按需加载**：`LazyVerticalGrid` 只创建视口附近的卡片，缩略图按尺寸降采样，共享缓存上限 8MiB。不再一次创建完整分类下的所有大图。
- 拖动照片参数立即更新预览，但草稿写盘延迟 250ms 合并；应用过程中暂停独立预览，避免它与重新绑定的实际双槽同时竞争 GPU。

没有降低实际壁纸分辨率、减少 shader 通道、替换蒙版或修改原生库。Cosmic/Gradient 渲染器和第四轮 `PhotoPowerGate` 不变。曾试过直接在 Choreographer 回调里提交 GPU，测试没有稳定收益，最终撤回，保留原来的 Handler 提交顺序。

## 息屏位置是否固定

第四轮及之前使用固定的比例锚点，不是固定像素：圆景中心默认约在屏幕高度的 16.5%，留光中心约 18.5%，水平方向居中。它们**没有跟随系统时钟，也没有实现壁纸自身的防烧屏位移**。

第五轮新增：**编辑页 → 息屏 → 位置**。

- 横向偏移限定在屏宽 ±20%；纵向偏移为屏高 -2% 到 +40%，正值向下。
- 移动的是整个圆球/相框，不是图片裁切。取景、锁屏纹理与位置分别设置。
- 圆景与留光共用照片草稿及偏移量，各自默认锚点保留；恢复默认位置不会重置取景。
- 老配置缺少新键时偏移量为零，不改变现有构图。应用后才复制到生效配置。
- 进入锁屏/桌面仍展开到原来的全屏终点，再息屏回到用户设置的位置。

手动位置调节**不等同于防烧屏功能**。这一轮没有宣称已经完成系统时钟跟随或 OLED 防烧屏适配。

## 二三级页面

参考来自用户提供 APK 中 `EditorActivity` / `LibraryActivity` 的本地静态布局与事件定义：全屏预览、息屏/锁屏/桌面切换、随状态改变工具、当前页应用。只参考交互结构，不复制其可执行类或原界面资产，也不宣称像素级复刻。

原流程：选择卡片 → 滚回顶部 → 预览 → 展开一大组取景设置 → 返回壁纸库 → 应用。

新流程：**壁纸库点卡片 → 全屏编辑 → 右上角应用**。

- 壁纸库取消大封面与重复“预览/应用”入口，按分类浏览直接进入编辑。
- 编辑页持续保留全屏渲染视口；三态切换与工具悬浮其上，不挤压壁纸宽高比。
- 息屏显示位置入口；锁屏显示纹理入口；照片、取景、演示与选项就近可达。
- “位置 / 取景 / 纹理 / 选项”分别打开 Miuix 底部面板，不在同一长表单里混排。
- 选择留光相框取景会切到息屏预览；选择整图取景切到锁屏，避免编辑看不见的对象。
- 缺图时直接提供选图入口；失败保留明确消息；未渲染成功时不开放应用按钮。
- 编辑保存为草稿，不直接更换壁纸。应用前保留冲突检查、Root/框架预检、双槽回读和确认对话框。
- “运行与诊断”从壁纸库标题栏进入，不与壁纸编辑的主要操作混在一起。没有新增未实现的时钟样式/桌面特效按钮。

继续使用 HyperExtreme 的 Miuix 0.9.4、中文、主题和独立 Activity 系统转场，没有改成网页或另起一套主题。

## 实验与证据边界

手机已安装第四轮 vc9。没有覆盖安装本候选、改变壁纸、操作电源键、修改 LSPosed 或抢占用户前台应用。

### 1200×2670 消费窗口 ABBA 对比

同一手机、人工测试图、同一原生库。顺序为旧版、新版、新版、旧版，各执行圆景与留光。仅取实际展开/收拢中的窗口，不把静止停绘计为丢帧。

| 指标 | 第四轮 | 第五轮候选 |
| --- | --- | --- |
| 留光转场帧间隔 P95，两次 | 34ms / 34ms | 19ms / 20ms |
| 圆景转场帧间隔 P95，两次 | 18ms / 19ms | 18ms / 21ms |
| 留光静止 2 秒提交帧，两次 | 122 / 244 | 0 / 0 |
| 圆景稳定自转 2 秒提交帧，两次 | 175 / 197 | 62 / 61 |

这支持留光等待减少和静止绘制负载下降，**不能说圆景转场 FPS 已明显提高**。测试期间系统刷新率会改变，最后一次旧版留光结束时为 120Hz，其余记录的起止值约 60Hz；没有锁定温度、前台负载或频率。完整输出见 `evidence-v5/perf-comparison.json`，不把这些窗口结果换算成整机省电百分比。
