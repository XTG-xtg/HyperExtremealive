# 统一息屏亮度与 Infinity 转场

2026-11-15，更新至 ui32：覆盖 Alive 动态／照片／视频／立体、Infinity、Vivo 液态／趣味光栅／闪卡，以及独立空间、光栅与视差壁纸。空间和光栅同时覆盖 Hook 与系统壁纸服务模式。

## 调节入口与保存

- Alive、Infinity、Vivo：预览编辑器 → 选项 → 息屏亮度；修改后即时预览，应用壁纸时保存，预设继续保留该倍率。
- 独立空间、光栅、视差：详情页点击“预览与应用”或“预览与调整”，进入共用 Alive 外观的全屏三态预览；“息屏亮度”打开底部面板。取消不写入配置，应用后保存。空间使用生成的真实分层和裁剪，光栅使用所选搭配，视差预览当前背景与移动参数，系统主体以实机为准。
- ui32 按用户要求改为固定 0–5 的线性滑块，20 格、每格 0.25（含两端共 21 个停靠点）。删除倍率输入、设置倍率与快捷倍率按钮。0 表示不修改系统原始息屏亮度；非零最大 5 倍。旧配置超过 5 的值读取时限制为 5，旧高倍率预设迁移并保留封面和原记录备份。
- 这是壁纸画面的曝光倍率。纯黑保持黑色，纯白是显示输出终点；不会突破面板的物理亮度或改变系统 AOD 开关。

## 渲染与生命周期

ui35：在本模块原生壁纸的全屏 AOD、非零亮度会话内，保持首次有效 Doze 亮度请求，并移除额外环境光压暗层；普通亮屏、完整黑色遮挡和会话结束不受此保持影响。Infinity 移除 1.6 秒亮度脉冲，避免星点先亮后暗，多边形分组继承当前显示程度。详见 `UI35-AOD-FIXED.zh-CN.md`。

ui34 当前规则：非零亮度移除全屏 AOD 的系统壁纸遮罩，曝光由滑块控制；0 恢复原始遮罩，自定义全黑 AOD 与自动关闭不变。这里的画面亮度不等于屏幕物理亮度；系统 Doze 仍可降低面板亮度。此前版本的遮罩补偿／保持说明保留为历史记录，详见 `UI34-AOD-UNMASKED.zh-CN.md`。

`AodBrightness` 统一数值校验、配置通道和空间／光栅的 GLSL、AGSL 曝光算法，沿用 Alive 公共呈现通道的黑色保持曲线。主体先还原非预乘颜色，再调整并重新预乘，保持透明轮廓。

Hook 模式由现有息屏压暗进度同步曝光，配置更新通过可信配置 Provider 和 ContentObserver 传递，不引入系统属性轮询。服务模式监听电源、显示与 ambient 回调，采用 700ms 连续曝光过渡；快速反向切换从当前帧继续。隐藏、真正 OFF 或稳定后不增加绘制循环，显示刷新率及 DOZE/SUSPEND 通知不会重启稳定动画。

ui32：非零倍率使用本次进入息屏时的压暗基准，后续环境光回调不能把壁纸压暗值重新改低；唤醒、全黑隐藏／自动关闭息屏显示或选择 0 时释放基准，继续系统流程。Alive 公共呈现通道及封面生成将 0 映射为曝光 1，避免 0 被误作全黑。画面曝光与压暗保持不等于锁定屏幕面板的物理亮度。

ui32 的构建、验证和交付记录见 `UI32-AOD-SLIDER.zh-CN.md`。以下 ui27 与 ui26 内容保留为历史记录；其中“无固定上限”和旧页面入口已被 ui32 规则替代。

ui33：大于 1 的额外曝光只在 AOD 阶段使用。收到唤醒状态或转入锁屏／桌面后，首帧撤销高曝光，不再随着展开动画延续约 700ms；空间、光栅服务以交互状态为准，忽略滞后的 DOZE 状态，防止再次提亮。低倍率继续平滑恢复，其他转场不变。实现与验证范围见 `UI33-AOD-WAKE.zh-CN.md`。

## ui27：真实息屏的系统遮罩

用户反馈所有壁纸在预览中变亮明显，实际息屏变化不明显。应用流程确实会保存倍率并重建真实引擎；只读状态也确认已应用倍率。差异在于预览只有画面曝光，系统壁纸还会在曝光之后再被 HyperOS 压暗。

本机 ROM 的 `MiuiFullAodManager.computeFullAod` 根据面板亮度生成 0.3～0.8 的壁纸压暗参数，再通过 `KeyguardPanelViewController.doWallpaperBlackAnim(boolean,float,int,boolean,AnimationTracker)` 更新壁纸。即使 shader 已输出纯白，后续系统压暗仍然存在，继续增加画面曝光无法突破这一层。参数到最终亮度的转换由 ROM 合成实现决定。

ui27 将大于 1× 的倍率同时用于遮罩：`black / brightness`。例如系统给出 0.8 压暗强度时，2× 改为 0.4，5× 改为 0.16。1× 及以下保留原系统遮罩，依然通过画面曝光控制变暗；倍率继续无固定上限。

- 原生壁纸服务：只匹配本机已核对的方法签名、进入全屏 AOD、`type=1` 和当前用户实际绑定的本模块 Home／Lock／Spatial／Raster 服务。只替换遮罩参数，继续执行系统动画、景深回调与资源清理。动态环境亮度回调同样生效。
- 当前用户来自 ROM 的 `selectedUserInteractor`；空的锁屏 `WallpaperInfo` 只有在锁屏 ID 为 -1（桌面共享）时才回退到桌面，独立静态锁屏不受桌面壁纸影响。未知契约保留系统行为。
- Hook 空间／光栅：自绘 GL 与主体 AGSL 使用同一补偿遮罩，原始压暗进度继续用于曝光和反向过渡，配置变化可直接重绘。
- 全黑自定义 AOD、其他壁纸与唤醒目标不变。没有调整屏幕面板亮度；真实息屏亮度仍受系统及硬件控制，预览与实机不能按肉眼绝对亮度等同。
- 引擎诊断增加 `configured_aod_brightness` 和 `rendered_exposure`；SystemUI 命中补偿时记录原始遮罩、调整值和倍率。

新系统层代码需重启 SystemUI 所在进程后加载；交付时提示用户重启手机，未代用户重启、切换壁纸或操作息屏测试。

ui27 本地验证：遮罩数值与范围、方法参数保留、配置传播、服务转场、真实服务归属及当前用户反射路径的定向回归通过。Debug APK 构建成功，版本号 42 / `0.5-alive.7-ui.27-aod-brightness`，签名校验通过并与 ui26 一致。构建日志位于 `build/aod-dimming-fix-20261115/`。本轮未运行手机上的显示或息屏测试，系统层实际效果待用户重启后验收。

## Infinity

20 款样式的稳定息屏星点增益提高 60%，桌面／锁屏星点增益不变。桌面到息屏加入一次约 1.6 秒的星点强调；S8／N8 星空移动幅度增大，背景淡出延长至 1.2 秒。S8／N8 背景合成改为加权相加，避免 AOD 淡入将正在淡出的桌面再压暗一次。反向切换保留当前星点亮度，稳定后停绘。
