# ui33：退出 AOD 时撤销额外曝光

版本：48 / `0.5-alive.7-ui.33-aod-wake`。

用户反馈调高息屏亮度后，从 AOD 回锁屏会先闪亮再变暗，暂不能确认时钟是否同时变亮。

代码中原先让 AOD 的高曝光随着场景进度继续淡出约 700ms；此时系统面板和壁纸压暗已经开始恢复，锁屏展开画面仍可能叠加高倍率。该路径能导致用户描述的亮度过冲，但未用实机录屏确认它是唯一原因。

- Alive、Infinity、Vivo 共用呈现通道在退出 AOD 或收到 interactive 唤醒状态后，首帧不再施加大于 1 的额外曝光。位移、展开及系统压暗动画不改。
- 空间、光栅服务采用同一曝光规则；PowerManager 已确认唤醒时，不再被滞后的 DOZE 显示回调重新启用高曝光。
- 空间 Hook 和视差背景同样在退出目标确定后撤销额外曝光；光栅 Hook 原先已在退出时直接恢复 dim=1，曝光权重随之为 0。
- 0 的旁路语义、0.25–1 倍的平滑压暗恢复、稳定 AOD 的指定亮度与自动关闭流程保留。没有修改屏幕面板亮度或时钟亮度。

回归覆盖唤醒首帧、连续反向切换、滞后 DOZE 通知、低倍率渐变、稳定 AOD 保持和空闲停绘。测试不替代实机视觉验收；未操作手机息屏、指纹或压力测试。
