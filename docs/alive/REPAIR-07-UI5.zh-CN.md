# UI5：独立标识与主线 Beta2 合并

版本：`0.5-alive.7-ui.5` / versionCode `20`。

## 本轮内容

- 应用名称改为 **HyperExtreme Alive**，安装包名改为 `com.xtg.hyperextremealive`。
- 合并 [HyperExtreme 0.5 Beta2](https://github.com/22Frederic/HyperExtreme/commit/e4f7626d9f5ee77ea3603ddbd6f90ea8781119d8)，保留主线提交历史。
- 接入主线多图光栅壁纸、空间壁纸显示区域裁剪、共用卡片流及候选排序、AICR 主体处理、系统壁纸服务权限入口与相关渲染修复。此光栅壁纸独立于 Alive 库内的 Vivo 趣味光栅。
- 保留 Alive 入口、照片／动态预览、四位贡献者关于页，以及未完成应用的恢复和停用后保留照片的逻辑。
- README 只保留项目介绍、使用方式和末尾鸣谢，不放更新流水账。

## 合并时保留的保护

- Alive、空间、光栅、视差统一参与互斥；读取不到壁纸状态时不继续切换。
- 空间／光栅的系统服务按安装包名和完整服务类名共同识别；关闭只处理该功能绑定的槽位，不清除其他功能或主线的壁纸。
- 光栅控制命令串行执行；停用未确认时保留待关闭状态，页面显示“重试关闭”，不允许直接启用另一条链。
- 空间裁剪参数随启动一起发布；同图裁剪变化时保留主线的重新装载流程。非法或非有限参数不会传给 shell／GPU。
- 批量清理先请求停用，再在切换锁内复查是否被重新启用；未确认停用时不删除缓存。
- 空间停用后的壁纸进程重载在释放切换保护前完成，避免延迟重载打断新选择。
- 系统服务目标采用原子写入，写入失败不打开选择器、不伪装成应用成功。

## 包名边界

Java/Kotlin 和 JNI 类命名空间保留 `com.frederic22.hyperextreme`，避免破坏原有类入口。
安装标识、Provider authority、权限目标、Root helper、跨进程广播、系统属性和模块专属共享文件均使用本分支身份。
Manifest 使用完整组件类名；helper 构建依赖统一的 `ModuleIdentity`。

这是独立安装，不会覆盖主线或旧包名版本，**不会自动迁移旧配置**。
可同时安装不等于可同时启用重叠钩子；切换使用时请停用另一个模块的相同功能，并在 LSPosed 确认新包名模块的推荐作用域。
主线新增推荐作用域 `com.xiaomi.aicr` 已保留；本轮没有替用户修改作用域、重启或安装。
