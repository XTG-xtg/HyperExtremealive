# ui22：删除时钟与通知扩展

版本 `0.5-alive.7-ui.22-trim1`，versionCode 37。

按使用反馈删除失效的时钟替换和通知光效功能，包括实验扩展页、编辑器入口、66 款时钟样式、字体、预览图、原版时钟 APK、Vivo 时钟布局、Flyme DEX、SVGA 光效及兼容桥。旧版额外 TextClock 叠加也已移除。

`native-clock/`、`notification/` 和只供该扩展使用的 `ui/editor-ui.apk` 均不再位于源码资源目录或新 APK 中。构建不再生成时钟兼容桥；压缩资源读取器只保留 Vivo 壁纸使用的两份运行库。

旧偏好中的时钟和光效开关不会再触发这些功能。历史壁纸预设仍可解析；确认新预设时关闭废弃的时钟位。系统原生时钟继续由系统绘制，Alive 的系统时钟位置读取、息屏图案跟随、防烧屏位置与 AOD 壁纸显示保护继续工作。

Alive 动态资源 ZIP 格式与 ui21 相同，之前的 v1 配套资源包可以直接复用；中央导入/下载按钮、导入后隐藏按钮和显示分类的行为保留。Infinity、Vivo 壁纸和照片功能继续内置。

回归重点包括旧偏好不会重新启用扩展、APK 内扩展资源和 Activity 不再存在、AOD 显示保护、系统时钟布局跟随、预设恢复、动态资源导入和 Infinity/Vivo 素材读取。自动测试不代表本版已经在小米 15 验证。

本地变更记录及备份位于 `build/remove-clock-notification-20261114/`。历史导入来源保留在 `IMPORTED-EXTENSIONS.json`，并标记为已删除。
