# UI.10 编辑器细节整理

日期：2026-11-10。版本：`0.5-alive.7-ui.10`，versionCode 25。

## 设计范围

保留 HyperExtreme 的 Miuix 设置页结构，不更换系统字体，不改写空间、光栅主页。
照片编辑维持深色画布，时钟设置跟随应用深浅色。蓝色只用于主操作与选择反馈。

### 蒙版

- 画布、状态说明、工具坞分层，不再堆叠七个同级文字按钮。
- 画笔、擦除、框选有独立线性图标及选中态；没有历史时禁用撤销。
- 原图对照不修改蒙版，对照期间暂停绘制。画笔提供接触位置与尺寸轮廓。
- 画笔与框选共用稳定高度，切换工具不会缩放或移动照片。
- 框选外区域轻微压暗，以细边框和角标指示选区；只有框选模式显示“识别选区”。
- 自动识别、清空、完成分别处于不同操作层级。清空仍可撤销。
- 小屏、大字体下工具坞可以滚动；保存、忙碌及禁用状态保留原有约束。

### 时钟与通知

- 去掉重复状态栏留白；以实际时钟内容为预览主体，单独整理样式、大小、颜色及通知光效。
- 使用包内原始缩略图，运行时移除其全屏黑色空白；不生成或伪造系统时钟图。
- 真实组件使用独立预览容器等比缩放，不改变 SystemUI 接入容器或原版字体布局。
- 大小、颜色调整复用已加载组件，不在每次拖动时重复加载运行时或闪烁加载状态。
- 原版组件加载失败时，有参考图则明确标注“静态参考”；无参考图则显示不可预览状态。
- 静态参考不能解除实时就绪校验，开启时钟替换后仍需真实组件就绪才能应用。
- 样式卡统一高度和选中边框；颜色提供名称及单选语义；播放光效先滚回预览区域。
- 草稿仅在“应用”时保存，不因打开、选择、取消或播放预览而启用系统功能。

### 共同细节

- 统一编辑顶栏的间距、按钮尺寸、标题字重；完成操作不再重复使用大块灰色按钮。
- 分段选择器跟随主题，提供选中动画及实际禁用语义。
- 取景、位置、灵敏度等滑块统一标题、数值和间距；补充禁用无障碍状态及回调保护。
- 精简液态壁纸设置中的长段说明，避免右侧下拉值挤压左侧文案。
- 预览工具栏为时钟、主体范围使用对应图标。

## 验证与边界

- Robolectric / Compose：正常尺寸、320dp 小屏、1.4 倍字体、深浅色、蒙版工具切换、原图对照、撤销、禁用、草稿隔离、时钟失败状态及样式画廊。
- 时钟预览容器测试：保持原始布局宽度，纵向内容及最大用户缩放不溢出容器。
- 实机 UI 检查：Redmi K30 / Android 12，仅使用 `legacyUiSmoke` 调试包。检查蒙版绘制、撤销、对照、框选、时钟页面及样式弹层；不应用壁纸或启用模块。
- Android 12 不在正式支持范围内，部分原版时钟组件不能在该备用机实时加载。该设备的静态参考和失败状态不构成 HyperOS 原版时钟或息屏钩子验收。
- 正式 Release 仍为 Android 13+；调试兼容开关不得用于 Release。
- 全量 lint 仍报告三个此次未修改区域中的错误：`DesktopWallpaperInjector.kt` 的壁纸读取权限检查，以及 `ParallaxBg.kt`、`ScreenFlash.kt` 的旧注册广播分支标记检查。未新增 baseline，未关闭检查。

本轮源码备份、构建日志和备用机截图位于本机 `.reference/ui10/`；截图测试输出位于 `app/build/reports/alive-ui/ui10-*.png`。这些本机验证材料不进入源码发布包。
