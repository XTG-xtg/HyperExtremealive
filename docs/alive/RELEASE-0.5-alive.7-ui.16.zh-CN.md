# HyperExtreme Alive UI16

`0.5-alive.7-ui.16` · versionCode `31` · ARM64 · Android 13+ · target SDK 37

本次发布汇总 UI7 正式版之后的更新，重点修正 Alive 新建壁纸流程、可见息屏动画、首次息屏首帧交接和解锁动画触发时序。

## 主要更新

- **新建后直接预览**：Alive 照片和液态壁纸按“新建 → 选图 → 预览 → 确认应用”的流程操作，不再选完图就藏入草稿，也不直接跳到系统动态壁纸选择页。
- **可见息屏持续动画**：系统仍显示 AOD 时，不再因 3 秒兜底窗口结束而提前停止动画；真正关闭显示或隐藏壁纸后停止绘制。
- **首次息屏首帧交接**：自选照片及支持的动态系列在桌面可见后提前准备一帧锁屏内容，减少换壁纸后首次息屏时临时初始化带来的空档。不会开启隐藏壁纸的持续渲染循环。
- **解锁动画更及时**：在系统确认开始退出锁屏时触发桌面动画状态，不再只等待较晚的解锁完成广播；保留息屏保护及取消解锁时的状态回退。
- 完善编辑器、Vivo 壁纸素材与区域编辑，以及渲染资源恢复。原版时钟和通知光效仍属于实验性扩展，不代表 OpenAlive 全功能验收完成。

## 安装与设置

1. 下载下方 APK 覆盖安装。同包名、同签名版本可保留配置；已安装并测试 UI16 的用户无需再次安装，本次上传的 APK 完全相同。
2. **更新后请手动重启手机**，使 SystemUI 中的新钩子生效。首次使用请在 LSPosed 中启用模块并确认推荐作用域。
3. 如需在 AOD 显示壁纸，请确认系统已开启息屏显示，并启用与锁屏壁纸一致的选项；选项名称和可用性依 ROM 而异。模块不强制改变系统显示时长或电源策略。

主要适配 HyperOS 4，依赖具体 ROM；不包含小米原有超级壁纸。包名为 `com.xtg.hyperextremealive`，不要与主线同时启用修改相同系统功能的选项。

构建为开启 R8 优化、关闭 debuggable 的 Release，沿用现有 Android Debug 证书以保持覆盖安装兼容性，尚非独立生产签名密钥。

## 验证结果与边界

- 244 项单元/Robolectric 测试及 1,381 项离线结构与资源检查通过。
- 小米 15 上，9 个首帧预准备、10 个渲染恢复及优化 APK 的 42 个代表性离屏渲染场景通过。
- 重启后的实际操作记录覆盖 3 次换壁纸后的首次息屏、7 次息屏循环和 8 次解锁：3 次首次息屏都在进入 AOD 前准备好首帧，未在息屏期间重新初始化渲染器。
- 动态壁纸的 5 次解锁中，Alive 状态在系统退出锁屏事件后 5–13 毫秒触发；这不是整段动画耗时或屏幕显示延迟。最快一轮应用后约 270 毫秒便息屏，首帧仍提前 93 毫秒准备完成。
- 本轮日志没有 Alive 渲染错误，但日志结果不能替代肉眼验收，也不保证所有机型、素材、快速操作或长期运行均无闪烁。

提前准备首帧目前覆盖 Cosmic/Phoenix、Bubble、Gradient、Stereo 和六类照片壁纸，**不包含视频与 Vivo 运行时系列**。Surface 重建、内存压力，或在准备完成前立即息屏，仍可能进入冷启动路径。其他 ROM、视频解码和长期 AOD 功耗不属于本轮完整验证范围。

实现及验证细节见 [UI16 技术记录](UI16-DYNAMIC-HANDOFF-UNLOCK.md)。附件沿用上一正式版格式，仅提供 APK 与 `SHA256SUMS.txt`；对应源码见本 Release 的 Git 标签，匹配的 R8 映射已本地归档。
