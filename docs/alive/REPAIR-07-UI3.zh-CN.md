# 预览过渡与照片面板：0.5-alive.7-ui.3

日期：2026-11-06。versionCode 18。基于已交付 ui.2 修改。未安装候选、修改实际壁纸或操作手机电源。

## 本轮交互

- 「样式」中照片/动态分类使用淡入淡出、轻微横移和高度过渡，保持原缩略图与分组。
- 选择壁纸时，先用 160ms 淡出当前画面，在遮盖下替换引擎，等待新引擎首帧后用
  280ms 淡入。不是两个 GPU 渲染器同时交叉混合，不截图用户壁纸，不额外开启一个渲染器。
- 新 EGL attach 带独立 generation；不能用旧引擎已出帧的状态提前揭开新画面。
  覆盖层完成动画后留出 Compose 绘制帧；取消时清零遮盖、释放交互锁，尊重系统动画倍率。
- 取景页「返回 / 完成」与预览「取消 / 应用」共用椭圆按钮、尺寸和顶栏间距。
- 照片面板跟随当前预览：锁屏改锁屏，桌面改桌面，留光动态息屏改相框。
  留光全屏照片息屏使用锁屏照片；照片入口与取景入口采用同一目标规则。
- 按最新反馈去掉照片面板全部小字备注与大按钮。桌面只显示两行：
  「跟随锁屏」开关、「选择照片」右箭头设置项。锁屏/相框只有「选择照片」。
  两行沿用项目已有 Miuix BasicComponent 的字号、间距、触感和按压反馈。
- 跟随使用锁屏照片与取景，但桌面纹理仍独立；开启不清空已选独立桌面照片及取景。
  关闭可以回到之前的独立设置；成功选择新桌面照片才自动关闭跟随，取消选择不改变状态。
  跟随期间主动编辑桌面取景会以当前锁屏画面为起点建立独立桌面取景。
- 以上都是草稿操作，不会自动应用到系统壁纸。

## 安装后建议复测

1. 预览内往返照片/动态分类和多个引擎：画面有过渡、保持当前息屏/锁屏/桌面模式。
2. 桌面照片面板只有开关与选择行。选独立图后关闭跟随；重新开启后使用锁屏图，
   再关闭能恢复独立图。取消系统选图器不改变开关。
3. 两侧分别选择纹理、取景，确认互不覆盖；不点应用就退出，实际壁纸不变。
4. 切换期间将应用放到后台再返回，确认没有残留黑色遮盖或不可操作按钮。
