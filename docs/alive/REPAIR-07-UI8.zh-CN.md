# ui.8：时钟与通知离线实验候选

版本：`0.5-alive.7-ui.8` / `23`，包名和签名延续 ui.7。
本轮没有连接或操作设备，没有推送 GitHub 或发布 Release。**不是 OpenAlive 全功能移植完成版。**

## 可用入口与实现

Alive 首页与息屏预览底栏新增「时钟与通知」。编辑过程中只操作本页草稿；应用只保存独立扩展配置，
不重绑壁纸、不刷新照片纹理、不更改系统时钟设置。系统返回和取消不保存。

- 66 个时钟预设：18 个 HyperOS、6 个 Flyme 布局和 42 个 Vivo 布局。
  使用引入的原版控件／布局和字体，不用 TextClock 冒充。Vivo 的部分厂商控件按上游适配为公共控件，
  因而不宣称移植了完整 OriginOS 时钟引擎。HyperOS／Vivo 选择器使用各自的上游缩略图，
  Flyme 布局使用文字选项加当前原版控件预览，不冒用其他样式的图。
- 独立编辑颜色、大小及息屏／锁屏效果预览。**运行时仅替换 AOD 时钟，锁屏仍使用系统时钟**；
  本页是适配后的独立编辑承载层，不是 ColorOS 的原生编辑 Activity 或系统插件协议。
- Flyme 原始 SVGA 光环／双侧光带，5／10／15 秒上限，本页可播放。运行时跟随
  `NotificationAnimationView.startAnimation/stopAnimation` 的已批准窗口；不读通知标题正文，
  不主动请求点亮 AOD，不延长原生窗口，不跳过勿扰／省电条件。系统未启动通知动画时不会额外点亮。
- 指纹按下立即隐藏新增内容、恢复原生内容；抬起后延迟复核，旧代回调不能恢复新一次按压，
  两秒看门狗也只有在原生明确报告松开后才恢复。亮屏、停止 Doze、遮挡、停用、detach 均让回系统。
  只遮住已被替换的具体时钟／通知动画 View，保存并恢复系统最新请求的 alpha；
  **不修改指纹图标、HBM、认证结果、锁屏安全界面或整个 AOD 父容器的 alpha**。
- 替代时钟继承原生父容器防烧屏位移，跟踪时钟叶节点的 top margin／translation 等变换；
  已有壁纸几何观察器也能识别新时钟。实际时钟与图案跟随结果仍待实机检查。

## 容错与开销

新功能默认关闭。缺少必需方法或 Hook 安装失败时保持系统样式。原版控件成功测量／布局后才遮住原时钟；
构造、测量、布局、绘制失败时回退。SVGA 绘制失败、过期或原生停止均清理自有图层；
系统关闭动画时不递归重播。时钟 tick 不设置新闹钟或获取唤醒锁。

原始 APK／DEX／字体只在进入编辑器或启用扩展时准备，资源解包、校验在后台进行；
DEX 以私有只读文件保存，按 SHA-256 固定版本并隔离加载。旧代预览任务作废，关闭页后注销时钟事件和动画。
不把这些运行库装成应用，也不加载它们的 Application 或服务。

原版资源使 APK 相比 ui.7 增加约 86 MiB。安装及首次使用扩展还需额外的私有缓存空间，
这是内置离线运行库的代价，不应把包体或首次解包开销隐瞒成零成本。

## 离线验证与边界

验证数字和产物摘要见 `VALIDATION-07-UI8.json`。执行内容包括：

- Gradle 单元测试、Compose 常规／窄屏控制面板交互及截图、R8 Release 构建和 lintVital。
- 草稿与保存、参数纠错、alpha 恢复、指纹旧代回调、光效有界期限、缺失 ROM 契约、退出清理、
  控件测量异常隔离、时钟停止期间回调重入及新时钟几何识别。
- 已有电源／照片／权限／运动逻辑离线回归。
- 原资源哈希、最终 APK 所含资产、隔离桥只含四个类，以及本地归档 MIUIAod 的实际 DEX 方法签名。

归档 MIUIAod SHA-256：`4f3b62bc17600beb3b732dbbfa4e3eb42a690c4050bbc722782a553200d3cc84`。
离线检查确认该版本的 MIUI 通知链路不能直接套用 ColorOS 的 pulse reason 1，故未使用猜测的脉冲 Hook。

**没有执行原版 DEX 在真实 ART／ROM 中的控件实例化验收，也没有实测通知窗口、指纹高亮、待机功耗或解锁动效。**
Robolectric 控制面板截图不是原版时钟成功运行的证据，静态签名匹配也不保证当前手机 ROM 一定兼容。
原生锁屏替换、系统编辑器插件协议、Vivo 完整玻璃采样和所有厂商指纹变体仍未完成。

## 下次实机验收

先保留 ui.7 配置并只打开一个扩展；依次验证原版时钟加载、再次进入 AOD、防烧屏位移、
指纹按下／抬起／取消／失败／成功、快速重复亮灭屏、原生通知动画开始／停止、勿扰和省电。
任一原版样式不可用时应保留系统内容，不能黑屏、留下透明时钟或遮住指纹。
确认后再评估锁屏编辑器与完整遮罩协议，不直接将此实验包发布为稳定版。
