# ui.9：液态选区、闪卡与壁纸预设

版本：`0.5-alive.7-ui.9` / `24`。正式包仍为 Android 13+，沿用原包名和签名。

## 使用变化

- 液态、趣味光栅、闪卡从动态壁纸列表独立出来，与 Alive、空间和已有光栅入口平级。
  「更换壁纸」直接出现在编辑工具栏和二级主页，不再藏在「效果与素材」里。
- Alive、Vivo 主页统一为左侧新建、中间当前／上次使用、右侧已保存预设；
  息屏／锁屏／桌面只留在编辑器。尚未应用的修改不会替换中间卡片。
- 编辑器可「保存预设」，主页可「保存当前草稿为预设」。照片、取景、蒙版、样式、
  图案及参数一起保存。应用前保留上一套与下一套配置，避免只剩最后一次修改。
  删除预设只移除卡片记录和封面，不删除当前壁纸或其他预设共用的照片、蒙版。
  更新前已经被覆盖且没有留存的历史无法凭空恢复。
- 闪卡五种样式使用原引擎实拍缩略图并命名为「虹彩流光、夜空星点、斑斓光斑、
  镭射光带、放射光束」。斑斓光斑的图案菜单位于样式卡片上方。
  倾斜提示仅在闪卡二级主页显示；预览可点「光效演示」。
  夜空星点保留原版强度与启动渐显，亮色照片上本来就较柔和，没有人工增亮。

## 液态与蒙版

- 预览、实际渲染、触摸命中使用一致的源图选区、取景与缩放映射；
  最终 GPU 合成恢复选区外原图，避免原生网格影响扩散到未选区域。
  缺失手动蒙版不再回退为整张照片。
- 默认以选区内触摸触发；自动亮屏／解锁／陀螺仪演示改为单独可选项。
  系统锁屏 Hook 只屏蔽已命中选区的双击息屏判断，不吞掉整个面板触摸流；
  选区外保留系统手势，认证、通知、媒体等交互区让回系统。
- AI 主体识别复用 HyperExtreme 光栅的系统 AICR 通道，提供本地 U²-Net 回退、
  来源说明、框选、画笔、擦除、撤销和手动修整。不是接入付费云端图像生成服务。
- 「效果范围」等下拉菜单改为独立窗口，避免被编辑器底部窗口遮住。
- 主体／涂抹蒙版可通过系统文件选择器导出 PNG，白色选中、黑色未选中，
  保持导入源图尺寸，不烘焙取景、不反选背景，也不会重新发起 AI 识别。
  内置 640×640 主体纹理按原引擎 UV 展开到 1080×2400；用户导入的错比例蒙版仍拒绝。

## 已执行验证

- 177 项单元／Compose 测试通过，0 失败、0 跳过；包含窄屏、大字、深浅色、
  下拉窗口层级、五种样式选择、预设持久化与数据隔离、损坏记录容错、PNG 导出。
- Debug、R8 Release、lintVital 构建通过；正式 APK 的 minSdk=33，versionCode=24，签名校验通过。
- 前段主力机验证：液态四种样式的 GPU 选区外像素变化为 0；
  锁屏选区内双击触发液态而保持亮屏，选区外双击进入息屏，滑动解锁保留。
  用户要求脱离主力机后不再操作该机，最终 UI 包未安装到主力机。
- 闪卡离屏测试覆盖五样式、四范围及图案／姿态组合，按原引擎启动与运动时间推进；
  五张展示图来自这些真实 GPU 输出，来源与校验和见 `vivo/preview/flash-styles/source.json`。
- 备用 Redmi K30（MIUI 14 / Android 12）通过 root 安装专用调试包，实测主页、
  样式选择、图案下拉、原引擎光效演示、两套独立预设保存与重启恢复。
  液态效果范围菜单可选；本地 U²-Net 实际生成主体；内置和新生成的主体蒙版
  以及手动涂抹选区，经系统文件选择器成功导出 1080×2400 PNG；
  三份文件均检查到有效灰度选区，不是空文件或整张全白。

## 边界与安装

备用机包通过显式 `-PlegacyUiSmoke=true :app:assembleDebug` 构建，版本名带
`-ui-smoke-api31`。构建脚本禁止把该参数用于 Release 或包含 Release 的聚合任务。
它只验证所测 UI／渲染路径；未宣称整套系统 Hook 或空间编辑器兼容 Android 12。
不将这个调试包当作正式 Android 12 支持发布。

本轮没有在备用机上启用／验收完整 LSPosed 锁屏与 AOD 联动，没有进行整夜功耗测试。
旧版时钟与通知扩展的限制仍以 ui.8 说明为准。最终优化 Release 未做主力机安装回归；
需要后续在目标 ROM 检查系统联动，不应将离屏、Robolectric 或备用机结果替代它。

`deliverables/HyperExtreme-Alive-0.5-alive.7-ui.9.apk` 为正式最低 SDK 的本地候选产物；
源码归档和 R8 mapping 与 APK 一起保留，未向远端提交或发布。
